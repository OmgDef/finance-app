# Дизайн-бриф приложения для учёта финансов

Мобильное приложение для iOS и Android. Основной визуальный ориентир — тёмный интерфейс с заметными остатками, карточками счетов, компактной историей операций и четырьмя вкладками в нижней навигации. Функциональные требования и правила учёта описаны в [плане MVP](../../PROJECT_PLAN.md).

## Мобильные экраны

| Вкладка | Что показать |
| --- | --- |
| **Продукты** | Сверху сводка остатков в USD, EUR и RUB. Ниже карточки счетов, наличных и вкладов. На карточке счёта видны название, остаток и валюта. У вклада также видны справочная ставка и дата окончания. Из деталей счёта можно открыть историю и график платежей. Привязанная карточка показывает остаток своего счёта. |
| **Статистика** | Фильтры по периоду, счёту, категории и типу операции. Сводка доходов и расходов по валютам, расходы по категориям с подписями и суммами, история по дням. В строке истории видны название, категория и сумма с валютой. Нажатие на категорию открывает соответствующие операции. |
| **Платежи/переводы** | Действия «Записать расход», «Записать доход» и «Записать перевод», ниже раздел «Запланировано». Для перевода между валютами форма показывает два счёта, сумму списания и сумму зачисления. В графике видны ближайшие даты, периодичность и проведённые записи. |
| **Поддержка** | Кнопки «Написать на email» и «Позвонить», ниже раскрывающиеся ответы FAQ. Контакты берутся из админки, их можно скопировать. На экране активации контакты помогают запросить новый код. |

Вне вкладок нужны экраны активации по email и одноразовому коду, задания и подтверждения четырёхзначного PIN и разблокировки. Биометрия подключается по желанию через системный диалог. Для настроек часового пояса и биометрии нужен профиль. Предлагаем открывать его из «Продуктов».

Для макетов используйте вымышленные названия, остатки и операции. Проверяйте длинные названия и большие суммы на узком экране, увеличенный системный размер текста, читаемость при отрицательном остатке и различимость выбранной вкладки. Предусмотрите пустые списки, загрузку, ошибку связи, заблокированный доступ и переход на PIN после отмены биометрии. Используйте табличные цифры и обозначайте валюту рядом с суммой. Графики сопровождайте текстовыми подписями и значениями.

## Административная панель

Визуальные референсы относятся к мобильному приложению. Для админки зафиксированы рабочие разделы в плане MVP. При проектировании начните со списка пользователей и страницы пользователя со счетами, операциями и графиком. Форму исправления операции проектируйте вокруг причины изменения и предварительного просмотра нового остатка. Отдельные экраны нужны для контактов, FAQ и аудита.
