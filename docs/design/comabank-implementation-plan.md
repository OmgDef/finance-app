# Финальный план внедрения ComaBank

Внедри тёмный интерфейс ComaBank в существующую мобильную сборку `APP_VARIANT=b` для iOS и Android. Используй текущие команды учёта, модели, маршруты и правила доступа. Для A действуют текущий дизайн, название, ресурсы и поведение. Иконка ComaBank согласована. Правки мобильного клиента начинаются после утверждения макетов пользователем.

## 1. Брендинг и тема варианта B

- В `apps/mobile/src/app-variants.ts` задай `ComaBank` для английской и русской локализаций B. Проверь, как его использует `apps/mobile/app.config.ts` в названиях iOS и Android и системной строке Face ID.
- Используй утверждённый PNG в качестве основной иконки B. Подготовь из того же знака прозрачный ресурс для BootSplash и Android adaptive foreground и монохромный слой для тематических иконок Android. Если требуется восстановить геометрию знака, она описана в `paintMark` прототипа. Проверь знак под системными масками и на стартовом экране.
- Подключи тему через существующий `appVariant`. Используй фон `#09090B`, графитовую поверхность `#1B1A21`, основной текст `#F6F4FA`, вторичный `#ACA8B9` и акцент `#C497FF`. В `finance-ui.tsx` и общих компонентах сверяй контраст выбранного состояния, полей, ошибок, модалок и системных панелей. Проверь экраны проверки доступа, активации и PIN на остаточные зелёные стили B.
- Сохрани текущий идентификатор `com.tetafinance.app`, scheme `tetafinance`, локальное хранение, подписи сборок и выбор A по умолчанию. Проверь конфигурации Expo для обоих вариантов.

## 2. Счета, история и карты

- В `finance-screen.tsx` и `finance-dashboard.tsx` собери порядок блоков B по макету. Шапка ComaBank с переходом в профиль, три остатка в RUB, USD и EUR, затем «Счета и карты». «Движение денег» и «Курсы валют» идут ниже. Сохрани действующий расчёт по активным счетам, вывод каждой валюты отдельно и подсказку о часовом поясе, когда он ещё не выбран.
- На «Счетах» B убери вход в архив и кнопку «Записать расход». Архивные счета открываются через «Настройки» → «Управление счетами» → «Архивные счета». Сохрани доступ к истории архивного счёта из его управления. Действующие условия архивирования, восстановления и удаления счетов применяются в обоих вариантах.
- Под названием счёта покажи небольшие цветные миниатюры из `cardPreviews` и доступные последние четыре цифры. API возвращает до двух превью на счёт. Если `count` больше числа превью, покажи количество остальных карт и сохрани переход к полному списку через экран счёта.
- В `finance-account-overview.tsx` для B размести привязанные карты под текущим остатком, затем историю, динамику остатка и итоги за месяц. Показывай дату, заголовок, категорию и сумму операций из существующей модели. Сохрани выписку PDF, переход к операции, загрузку следующих записей и возврат на прежнюю позицию при навигации.
- Показывай карты плитками с их `appearance`, названием, логотипом платёжной системы и маскированными последними цифрами при наличии. Применяй `CardNetworkLogo` и контрастный цвет текста. Нажатие открывает существующий экран `finance-card-details.tsx` с крупной картой, остатком привязанного счёта, переходом в счёт и редактированием. Итоги по валютам учитывают каждый счёт один раз независимо от количества его карт.

## 3. Платежи и остальные экраны

- В B три кнопки «Платежей» называются «Расход», «Доход» и «Перевод». Для EN используй `Expense`, `Income` и `Transfer`. Сохрани быстрые категории, автоподстановку категории, валидацию и форму по типу операции. Для перевода между валютами сохраняются отдельные суммы списания и зачисления. Настройки расписания открываются из «Настроек».
- Сохрани пять вкладок в текущем порядке «Счета», «Статистика», «Платежи», «Помощь», «Настройки». Оформи выбранную вкладку по макету B с учётом возможностей текущей нативной навигации. В статистике сохрани период, фильтры, суммы по валютам, категории и переходы в операции.
- Приведи профиль, настройки, помощь и вложенные экраны B к той же тёмной теме. Сохрани настройки языка и часового пояса, PIN и биометрию, загрузку, обработку ошибок и повторные запросы. Проверь работу клавиатуры и отступы нижней навигации на iOS и Android.

## 4. Подключение поддержки ComaBank

- В `apps/mobile/src/support-screen.tsx` передай `variant` из `appVariant` в запросе к поддержке вместе с `lang`. Пример для B — `GET /api/v1/support?variant=b&lang=ru`. Общий компонент используется во вкладке «Помощь» и до входа.
- Используй восемь двуязычных вопросов ComaBank из миграции. Контакты загружаются из API, открываются по email или телефону и копируются существующими действиями. При `null` соответствующее действие скрывается.
- Проверь стенд с применённой миграцией `0025` и API с поддержкой вариантов. В админке «Поддержка» → «B · ComaBank» можно задать свои email и телефон. Для проверки возьми синтетические контакты и убедись, что изменения B видны в B. Запрос старого клиента без `variant` возвращает данные A.

## 5. Сборка и критерии приёмки

В корне выполни проверки проекта. Серверный набор использует Node.js `26.13.1`, MySQL `8.4.13` и две отдельные тестовые схемы. Примени миграции к схемам, заданным через `TEST_DATABASE_URL` и `TEST_WORKER_DATABASE_URL`.

```sh
npm run check
npm run build
DATABASE_URL="$TEST_DATABASE_URL" npm run migrate
DATABASE_URL="$TEST_WORKER_DATABASE_URL" npm run migrate
npm test
```

Собери A и B по существующей инструкции для iOS и Android. Для сравнения используй разные тестовые устройства или симуляторы, поскольку у вариантов общий идентификатор. Для обеих сборок укажи тестовый HTTPS API. [Команды сборки](../../apps/mobile/README.md)

| Проверка | Ожидаемый результат |
| --- | --- |
| Установка и запуск B | На домашнем экране указано ComaBank и видна утверждённая иконка. Стартовый экран и интерфейс тёмные. |
| Счета B | Три валюты видны одновременно. Следом идут счета и миниатюры карт. Запись расходов открывается из «Платежей», архив доступен из управления счетами в «Настройках». |
| Счёт и карточки | Видна история, открывается выписка. Проверь счёт без карт, с одной, двумя и тремя или более картами, карту без системы или последних цифр и переход обратно в счёт. |
| Платежи и расписание | Проверь все три вида операций, быстрый расход по категории и перевод между валютами. Расписание открывается из «Настроек». |
| Поддержка | A и B показывают собственные контакты и FAQ на RU и EN. В B это работает до входа и после него. Изменения B в админке не затрагивают A. |
| Доступность | На узком экране и с увеличенным шрифтом читаются остатки, длинные названия, последние цифры и выбранная вкладка. Клавиатура и панели не перекрывают действия. |
| Контроль A | На сборке A сверь название, иконку, тему, вкладки, платежи и доступ к архиву с текущей сборкой. Проверь открытие счёта и возврат со вкладки. |
